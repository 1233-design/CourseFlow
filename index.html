Technique 1

Constraint satisfaction (CSP)

Variables are the weekly sessions. Domains are every (day, period, room) triple that physically fits the subject. Constraints forbid an instructor, a cohort or a room from appearing twice in one period, and keep a subject off the same day twice.

Solved with backtracking search using the minimum-remaining-values heuristic, degree tie-breaking, least-constraining value ordering and incremental forward checking.

Worst case O(dn) · exponential but heavily pruned

Technique 2

Greedy allocation

Sessions are sorted hardest-first (smallest domain, then highest conflict degree). Each one immediately takes the best feasible slot: the emptiest day, the emptiest period, and the tightest room that still seats everyone.

One pass, no backtracking — extremely fast, used as the baseline the other engines improve on.

O(n log n + n · D) · linear in practice

Technique 3

Graph colouring

Each session is a vertex. An edge joins two sessions that cannot share a period (same instructor, same cohort or same subject). Time slots are the colours, so a proper colouring guarantees no overlapping classes.

Coloured with DSATUR (most-saturated vertex first). A candidate colour is only accepted if the rooms of that period can still host every session — checked with bipartite matching.

O(V2) colour selection · NP-hard problem, greedy-approximate

Technique 4

Dynamic programming

Inside every time slot, rooms are packed by a bitmask DP: dp[mask] is the minimum wasted seats when the first k sessions are seated in the rooms of mask. It finds the globally best room assignment for that period instead of first-fit.

The result is reported as seats reclaimed and the resulting room utilisation.

O(2m · m · k) with m rooms per slot (m ≤ 12)
